SLIDE 14.5 The Empty Tree Invariant
CS 106B Lecture 08 Supplemental
EMPTY SUBTREE nullptr
Base Case Invariant: 0 edges, 0 vertices. Does not contribute height to parent frame.
SINGLE LEAF NODE root != nullptr
Inductive Step: Leaf computes 1 + max(0, 0) = 1. Solves student question Alex K.
// C++ Canonical Implementation
int treeHeight(TreeNode* root) {
  if (root == nullptr) {
    return 0; // Empty tree has zero height (Invariant)
  }
  return 1 + std::max(treeHeight(root->left), treeHeight(root->right));
}
